## CardboardOS - 2026.8
A new descendant of my old OS project, IncedinaryOS, it is meant to be more optimised, fast and more user friendly with a TUI mode like how MS-DOS executive worked. The required tools are GCC (or just install BusyBox), NASM, GDB and QEMU. There will be a wiki on how to use the operating system

# Required tools
Here are the required tools
- GCC
- - Or Busybox
- NASM
- GDB 
- - Optional
- QEMU

# How to build
For Windows:
```build_windows.bat```

For Linux
```build_linux.sh```

For macOS
```build_mac.sh```
